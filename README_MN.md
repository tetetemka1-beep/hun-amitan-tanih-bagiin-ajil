# Ухаалаг камер — Python + CustomTkinter

## Ажиллуулах

Энэ компьютер дээр шаардлагатай сангууд болон AI загваруудыг бэлдсэн.
Төслийн хавтас дотор терминал нээгээд:

```powershell
python uhaalag_camera.py
```

Камер автоматаар асахгүй. Цонхны **Камер эхлүүлэх** товчийг дарна.
Камерын индекс анх `0`; өөр камер ашиглах бол зогсоогоод `1`, `2` гэх мэтээр солино.
Мөн **Бичлэг сонгох…** товчоор локал видео нээж болно.

Өөр компьютерт шилжүүлсэн бол Python 3.11 буюу түүнээс шинэ хувилбарт:

```powershell
python -m pip install -r requirements.txt
python setup_models.py
python uhaalag_camera.py
```

Windows-ийн ердийн Python (`python.exe`) ашиглана. Torch болон OpenCV нь тухайн
Python хувилбарыг дэмждэг байх хэрэгтэй. Анхны удаа загваруудыг татахад ойролцоогоор
60 MB интернет хэрэглэнэ. Дараа нь танилт, бүртгэл, дохио локал ажиллана.

## Хүн бүртгэх — 50 зураг

1. Камер эхлүүлж, кадрт ганцаараа орж нүүрээ бүтнээр нь харуулна.
2. Бүртгэлгүй нүүр дараалан **3 кадрт** харагдвал цонхны дээд хэсэгт
   **«Бүртгэлгүй хүн илэрлээ»** мэдэгдэл, богино дуу гарна. Бүртгэлтэй хүний
   нэр таарвал ийм мэдэгдэл өгөхгүй. Нүүр харагдахгүй бол бүртгэлгүй гэж дүгнэхгүй.
3. Мэдэгдлийн **Шинэ хүн бүртгэх** товчийг дарж, овог, нэрээ оруулаад
   **50 зураг авч эхлэх** товчийг дарна. Зүүн талын **Хүн бүртгэх · 50 зураг**
   товчоор өөрөө эхлүүлж бас болно.
4. Толгойгоо аажмаар бага зэрэг эргүүлж, өөр өөр өнцгөөс харуулна.
   Доод хэсэгт `17 / 50 зураг` гэх мэт явцыг харуулна.
5. 50 тод нүүрний зураг бүрдвэл зураг, нэр, нүүрний векторууд хамт хадгалагдана.
   Дараагийн кадруудад бүртгэсэн нүүртэй харьцуулж овог, нэрийг харуулна.

Хэт жижиг нүүр, олон хүнтэй кадр, бүдэг/хэт харанхуй/хэт гэрэлтэй эсвэл яг
давтагдсан зураг тоологдохгүй. Эхний нүүрнээс эрс өөр нүүр гарвал зураг авалтыг
түр хүлээнэ. Камерыг зогсоох, цонх хаах, цуцлах үед дутуу бүртгэл үүсэхгүй.
Хувцас эсвэл биеийн дүрсээр хүний нэрийг таахгүй; нүүр харагдах шаардлагатай.

## Амьтан илрэх үеийн дохио

Амьтан дараалан **3 кадрт** илэрвэл дээд хэсэгт төрөл, тоо, цагтай мэдэгдэл
гарч, **хоёр богино дуут дохио** өгнө. Амьтан кадрт үргэлжлэн байвал **10 секунд**
тутам дохиог давтана. Дуу нь тусдаа урсгалд тоглож, камерыг гацахгүй ажиллуулна.
Хүн бүртгэж байх үед ч амьтны дохио ажиллана.

Амьтны нэр асуух, зураг цуглуулах, бүртгэл үүсгэх үйлдлийг хассан.
Амьтанд зөвхөн төрөл, илрүүлэлтийн хувь, тоог харуулна.

Зүүн талын **Амьтны дуут дохио** тохиргоогоор дууг хааж / нээнэ. Дуу хаалттай
байсан ч дүрс болон амьтны мэдэгдэл харагдана. **Хүний мэдэгдэл** тохиргоогоор
бүртгэлгүй хүний мэдэгдэл, богино дууг хааж / нээнэ. Хоёр тохиргоо хадгалагдана.
Бүртгэлгүй хүн үргэлж харагдвал мэдэгдлийг **30 секунд** тутам шинэчилнэ;
нүүрний зураг авч байх хугацаанд хүний мэдэгдлийг түр зогсооно.

Мэдэгдэл камерын дүрсийг хаахгүй, нэр оруулах формыг автоматаар нээхгүй.
Хүн, амьтан зэрэг илэрвэл хоёр мэдэгдэл хоёулаа харагдана. `×` товчоор
хаах эсвэл камерыг зогсоох хүртэл мэдэгдэл харагдана.

Одоо **YOLOv8s Open Images V7** (`models/yolov8s-oiv7.pt`) загвар ашиглана.
Өмнөх COCO загварт арслангийн ангилал байгаагүй; шинэ загвар арслангаар сургасан.
Программ хүн болон дараах 27 төрлийн амьтныг загварын бодит ангиллаас илрүүлнэ:
арслан, бар, ирвэс, гепард, шилүүс, тэмээ, ямаа, туулай, буга, үнэг, гахай,
нохой, муур, морь, хонь, үхэр, шувуу, заан, баавгай, эрээн тахь, анааш,
усны үхэр, хирс, кенгуру, сармагчин, хулсны баавгай, хэрэм.
Нэг амьтанд давхар гарсан хүрээг шүүж, давхар тоолохоос сэргийлнэ.
Шинэ загвар нь өмнөх жижиг загвараас CPU дээр удаан байж болно; бодит FPS-ийг
дэлгэцийн AI хурд хэсгээс харна.

## Толины тусгал

**Шууд камер** хэсгийн дүрсний **баруун дээд талын «Толины тусгал»** тохиргоог
асаахад зүүн, баруун талыг сольж харуулна. Унтраахад энгийн дүрс рүү буцна.
Камер ажиллаж байх үед шууд сольж болно; зогсоож эхлүүлэх шаардлагагүй.
Дүрс болон объектын хүрээ хамт эргэж, нэр, хувь, огнооны бичиг зөв чиглэлтэй үлдэнэ.
Тохиргоог SQLite санд хадгалж, дараагийн нээлтэд сэргээнэ.

Толины тусгал нь дэлгэцийн дүрсэнд үйлчилнэ. Нүүр таних, 50 зургийн бүртгэлд
анхны кадрыг ашиглах тул хуучин бүртгэлийн нүүрний вектор өөрчлөгдөхгүй.
Ctrl+S-ээр хадгалсан зураг тухайн үед дэлгэцэд харагдаж байгаа чиглэлтэй байна.

## Хувь, огноо, цаг

- **Илрүүлэлт: 94%** — YOLO-ийн тухайн хүн/амьтны bounding box илрүүлэлтийн итгэлцэл.
- **Төстэй байдал: 82%** — бүртгэсэн хүний нүүртэй cosine similarity харьцуулсан оноо.
  Хоёр хувь нь тусдаа утгатай; хэмжсэн нийт нарийвчлал, эсвэл нэр зөв байх
  магадлалын баталгаа биш.
- Хүний нэр тааруулах босго `0.50`, дараагийн хүнээс ялгарах зай `0.06`.
  Оноо хүрэхгүй эсвэл хоёр бүртгэл хэт ойролцоо бол нэр оноохгүй.
- Огноо, цагийг Улаанбаатарын **UTC+08:00** цагаар шууд дүрс, толгой хэсэг,
  үйл явдлын бүртгэлд харуулна.
- Хүн, амьтны тоо нь **тухайн кадр дахь тоо**. FPS нь AI боловсруулсан кадрын хурд.
- Илрүүлэлтийн доод босго анх **35%**. Зүүн талын гулсуураар **15–90%** дотор
  өөрчилнө. Хол эсвэл жижиг амьтан алгасагдаж байвал 25–35% болгож туршиж болно;
  хэт бага босго нь буруу илрүүлэлт нэмэгдүүлж болзошгүй. Дэлгэцэд бодит оноог харуулна.

## Бүртгэлээ удирдах

**Бүртгэлүүд** хэсэгт мөр сонгоод:

- Овог, нэр, тэмдэглэлээ засаад **Өөрчлөлт хадгалах** дарна.
- `‹`, `›` товчоор бүртгэсэн 50 нүүрний зургаа үзнэ.
- **Дахин зураг авах** дарж зургуудаа солино. Бүх зураг бүрдтэл хуучин зураг
  хэвээр үлдэнэ. Цуцалбал хуучин бүртгэлээ үргэлжлүүлэн ашиглана.
- **Бүртгэл устгах** үед баталгаажуулсны дараа нэр, зураг, векторуудыг хамт устгана.
- **CSV экспорт** товчоор бүртгэлийн мэдээллээ гаргана. Нүүрний зураг, вектор CSV-д орохгүй.

**Үйл явдал** хэсэг сүүлийн 100 илрүүлэлтийг харуулна; бүх түүхийг CSV-ээр экспортолно.
Нэг бүртгэл/төрөлд 10 секунд тутамд нэг мөр үүсгэнэ. Өнгөрсөн үеийн нэрийг
түүхэнд тухайн үеийн утгаар нь хадгална.

**Ctrl+S** — хүрээ, нэр, огноотой зургийг хадгалах. **Esc** — камер зогсоох.
Камер эхлүүлэх/зогсоох, цонхны X товчоор хаах үед capture суллагдана.

## Хадгалах байрлал

```text
uhaalag_camera.py             # CustomTkinter GUI, эхлэх файл
camera_engine.py              # YOLO, нүүр танилт, хүний зураг цуглуулах
camera_alerts.py              # Мэдэгдлийн нөхцөл, давталтын зай, дуут дохио
camera_store.py               # SQLite, бүртгэл засах/устгах, CSV
setup_models.py               # AI загвар татах, hash шалгах
requirements.txt
models/                      # Татаж бэлдсэн загварууд
camera_data/
  registrations.sqlite3      # Нэр, зураг (JPEG BLOB), вектор, үйл явдал
  snapshots/                 # Ctrl+S-ээр хадгалсан зургууд
  app.log                    # Алдааны тайлбар
tests/test_camera.py         # Автомат шалгалтууд
tests/test_alerts.py         # Хүний мэдэгдэл, амьтны дохио, дууны шалгалт
tools/verify_app.py           # Бодит загвар, GUI, камерын нэмэлт шалгалт
```

Зургууд SQLite файл дотор хадгалагдана; зураг бүр тусдаа файл болж задрахгүй.
Бүртгэлүүд хэсгийн галерейгаас үзнэ. Бүртгэл, нүүрний зураг болон камерын кадрыг
танилт хийхээр серверт илгээхгүй.

Хуучин хувилбарт амьтан бүртгэсэн бол тэдгээрийг шинэ хүний жагсаалт,
нүүр танилт, CSV бүртгэлд оруулахгүй. Хуучин өгөгдлийг автоматаар устгахгүй.

Программыг бүрэн хаасны дараа `camera_data` хавтсыг хуулж нөөцөлж болно.
Ижил компьютерт зэрэг хоёр хувилбар нээж нэг камераа ашиглахгүй байх нь тохиромжтой.

## Шалгах

```powershell
python -m unittest discover -s tests -v
python tools/verify_app.py --download-samples --models
python tools/verify_app.py --gui
python tools/verify_app.py --camera
```

Эхнийх нь бодит камер, интернетгүйгээр SQLite, 50 зургийн бүртгэл, цуцлалт,
дахин бүртгэл, нэр засалт, устгалт, хүний мэдэгдэл, амьтны дохио, 10/30 секундын
зай, мэдэгдэл давхардахгүй байх, camera release ажиллагааг шалгана.
Дууны автомат шалгалт mock ашигладаг; бодит чанга яригчийн дууг хэмжихгүй.
GUI шалгалт түр өгөгдлийн сангаар мэдэгдлээс хүн бүртгэл эхлүүлэхийг шалгана.
Камерын шалгалт цөөн кадр уншиж суллаад дахин нээнэ; зураг хадгалахгүй.

Бүртгэлийн 50 зургийн тоо болон дутуу бүртгэлийн ажиллагааг автомат шалгалтаар
баталгаажуулсан. Бодит гэрэл, хөдөлгөөн, хүмүүс ба амьтдын олон янзын нөхцөлд
танилтын хэмжсэн нарийвчлалын тайлан гаргаагүй.
